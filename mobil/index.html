Eine Zeile = eine Aufgabe. Reihenfolge der Angaben ist egal — nur Anzahl × Distanz steht vorn.

4x100 kr bz5 ab 1:40 "negativ split"

Serien (Klammern)

Mehrere Zeilen zu einer Runde zusammenfassen:

3x{
  4x50 kr bz6 ab 50
  100 locker bz1
}

= 3 Runden aus 4×50 + 100 locker.
